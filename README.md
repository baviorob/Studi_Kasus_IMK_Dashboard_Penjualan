Studi Kasus IMK: Dasbor Interaktif Monitoring Penjualan
Ringkasan
Proyek pembelajaran berdasarkan materi Interaksi Manusia dan Komputer (IMK), User-Centered Design, analisis kebutuhan pengguna, dan visualisasi data interaktif. Implementasi menggunakan Google Colab, Python, Pandas, Plotly, dan ipywidgets.
Cara menjalankan
1. Buka https://colab.research.google.com/
2. Pilih File → Upload notebook, lalu unggah Studi_Kasus_IMK_Dashboard_Penjualan.ipynb.
3. Jalankan sel secara berurutan.
4. Saat diminta, unggah dataset_dummy_penjualan.csv.
5. Gunakan filter wilayah dan kategori untuk mengeksplorasi dashboard.
Keterkaitan materi
Menerapkan UCD, kebutuhan fungsional/non-fungsional, Overview First, Zoom and Filter, Details-on-Demand, line chart untuk tren, bar chart untuk perbandingan, serta pengurangan chartjunk.
File
- Studi_Kasus_IMK_Dashboard_Penjualan.ipynb: notebook implementasi.
- dataset_dummy_penjualan.csv: dataset sintetis.
- README_Studi_Kasus_IMK.md: dokumentasi proyek.
Batasan
Dataset sintetis/dummy dan tidak merepresentasikan transaksi nyata. Checklist usability merupakan evaluasi awal; hasil yang valid memerlukan pengujian dengan pengguna sesungguhnya.
